# 客户端获取管理权限全过程分析报告

## 概述

本文档深入分析了 Gotify 服务端的权限管理体系，涵盖会话与令牌管理、权限提升流程、以及异常情况下的权限回收机制。

---

## 一、会话与令牌管理：服务端如何将令牌与特定客户端关联

### 1.1 令牌类型与生成

系统包含多种类型的令牌，通过前缀区分：

| 令牌类型 | 前缀 | 生成位置 |
|---------|------|---------|
| 客户端令牌 | `C` | `auth/token.go:43` |
| 应用令牌 | `A` | `auth/token.go:38` |
| 插件令牌 | `P` | `auth/token.go:48` |

**生成机制**：
- 令牌由随机字符串 + 前缀组成，随机部分长度为 22 字符
- 使用密码学安全的随机源 `crypto/rand`
- 字符集包含大小写字母、数字及 `._-`

**代码参考**：
- `auth/token.go:57-68` - `generateRandomToken` 函数
- `auth/token.go:61-68` - `generateRandomString` 函数

### 1.2 客户端与会话的关系

**客户端（Client）模型** (`model/client.go:10-38`)：

```go
type Client struct {
    ID            uint        // 主键
    Token         string      // 唯一令牌，用于认证
    UserID        uint        // 所属用户
    Name          string      // 客户端名称（如浏览器/设备名）
    LastUsed      *time.Time  // 最后使用时间
    ElevatedUntil *time.Time  // 权限提升有效期
}
```

**关键点**：
- 每个 Web 会话对应一个 Client 记录
- 令牌 `Token` 是客户端的唯一标识
- `UserID` 建立与用户的关联
- `ElevatedUntil` 记录权限提升的过期时间

### 1.3 会话创建流程（登录）

**入口**：`api/session.go:56-98` - `Login` 函数

**流程步骤**：

1. **Basic Auth 验证**
   - 从请求头提取用户名和密码
   - 调用 `a.DB.GetUserByName(name)` 查询用户
   - 使用 `password.ComparePassword` 验证密码

2. **创建客户端记录**
   ```go
   elevatedUntil := time.Now().Add(model.DefaultElevationDuration)  // 默认 1 小时
   client := model.Client{
       Name:          clientParams.Name,
       Token:         auth.GenerateNotExistingToken(generateClientToken, a.clientExists),
       UserID:        user.ID,
       ElevatedUntil: &elevatedUntil,  // 登录时自动提升权限
   }
   a.DB.CreateClient(&client)
   ```

3. **设置 Cookie**
   - Cookie 名称：`gotify-client-token`
   - 存储值：客户端令牌
   - 有效期：7 天 (`CookieMaxAge = 7 * 24 * 60 * 60`)
   - 安全特性：`HttpOnly=true`, `SameSite=Strict`, `Secure`（根据配置）

**代码参考**：
- `auth/cookie.go:12-21` - `SetCookie` 函数
- `model/elevate.go:16` - `DefaultElevationDuration = time.Hour`

### 1.4 请求认证流程

**中间件**：`auth/authentication.go:52-59`

支持的认证方式：

| 方式 | 位置 | 代码位置 |
|-----|------|---------|
| Basic Auth | Authorization 头 | `auth/authentication.go:124` |
| 客户端令牌 | X-Gotify-Key 头 | `auth/authentication.go:231` |
| 客户端令牌 | Authorization: Bearer | `auth/authentication.go:234-247` |
| 客户端令牌 | URL Query 参数 `token` | `auth/authentication.go:226-228` |
| 客户端令牌 | Cookie | `auth/authentication.go:218-224` |

**认证处理流程** (`auth/authentication.go:143-176`)：

```
handleClient()
    ↓
readTokenFromRequest() → 从多种来源提取令牌
    ↓
GetClientByToken(token) → 数据库查询客户端
    ↓
RegisterClient(ctx, client) → 注册到 Gin Context
    ↓
更新 LastUsed（每 5 分钟一次）
    ↓
执行权限检查（如 checkClientElevated）
```

**上下文注册** (`auth/util.go:22-24`)：

```go
func RegisterClient(ctx *gin.Context, client *model.Client) {
    ctx.Set(authKey, &authentication{client: client})
}
```

通过 `GetUserID()` 获取当前用户 ID 时，支持从 user/client/app 三种认证类型中提取。

## 二、权限提升请求的校验与执行流程

### 2.1 权限等级体系

系统定义了三级权限要求，通过中间件组合实现：

| 中间件 | 要求 | 适用场景 |
|--------|------|---------|
| `RequireClient` | 只需有效的客户端令牌 | 普通操作，如获取消息列表 |
| `RequireElevatedClient` | 客户端令牌 + ElevatedUntil 有效 | 删除客户端、修改密码等敏感操作 |
| `RequireAdmin` | 提升权限 + 用户是管理员 | 用户管理（创建/删除用户） |

**中间件定义**：
- `auth/authentication.go:46-48` - `RequireAdmin`
- `auth/authentication.go:52-54` - `RequireClient`
- `auth/authentication.go:56-59` - `RequireElevatedClient`

### 2.2 路由权限配置

**路由分组** (`router/router.go:183-236`)：

```go
// 普通客户端权限
clientAuth := g.Group("")
clientAuth.Use(authentication.RequireClient)
// GET /application, POST /application, GET /message, GET /stream 等

// 需提升权限
clientElevated := g.Group("")
clientElevated.Use(authentication.RequireElevatedClient)
// POST /client/:id/elevate, DELETE /application/:id, 
// DELETE /client/:id, POST /current/user/password

// 需管理员权限
authAdmin := g.Group("/user")
authAdmin.Use(authentication.RequireAdmin)
// GET /user, DELETE /user/:id, POST /user/:id
```

### 2.3 权限提升校验逻辑

**核心检查函数**：

1. **`checkClientElevated`** (`auth/authentication.go:258-263`)
   ```go
   func (a *Auth) checkClientElevated(client *model.Client) (authState, error) {
       if client.ElevatedUntil == nil || !timeNow().Before(*client.ElevatedUntil) {
           return authStateNotElevated, nil  // 返回 403
       }
       return authStateOk, nil
   }
   ```

2. **`checkClientAdmin`** (`auth/authentication.go:249-256`)
   - 先通过 `GetUserByID(client.UserID)` 获取用户
   - 检查 `user.Admin` 是否为 true

3. **`checkUserAdmin`** (`auth/authentication.go:265-270`)
   - 用于 Basic Auth 场景，直接检查用户的 Admin 属性

### 2.4 权限提升 API 调用链

**API 端点**：`POST /client/{id}/elevate` (`api/client.go:249-312`)

**请求体** (`model/elevate.go:8-14`)：
```json
{
    "durationSeconds": 900  // 提升持续时间（秒）
}
```

**处理流程** (`api/client.go:287-312`)：

```
ElevateClient(ctx)
    ↓
绑定 ElevateRequest 参数
    ↓
GetClientByID(id) → 检查客户端是否存在
    ↓
验证 client.UserID == auth.GetUserID(ctx) → 确保是自己的客户端
    ↓
计算 elevatedUntil = time.Now().Add(durationSeconds)
    ↓
UpdateClientElevatedUntil(client.ID, &elevatedUntil) → 持久化到数据库
    ↓
返回 204 No Content
```

**关键代码** (`api/client.go:304-308`)：
```go
elevatedUntil := time.Now().Add(time.Duration(params.DurationSeconds) * time.Second)
if err := a.DB.UpdateClientElevatedUntil(client.ID, &elevatedUntil); err != nil {
    ctx.AbortWithError(500, err)
    return
}
```

**数据库操作** (`database/client.go:66-69`)：
```go
func (d *GormDatabase) UpdateClientElevatedUntil(id uint, t *time.Time) error {
    return d.DB.Model(&model.Client{}).Where("id = ?", id).Update("elevated_until", t).Error
}
```

### 2.5 前端提升流程（两种方式）

#### 方式一：本地密码认证

**前端代码** (`ui/src/ElevateStore.ts:34-45`)：

```typescript
public localElevate = async (password: string, durationSeconds: number): Promise<void> => {
    await axios.create().request({
        url: `${config.get('url')}client/${this.currentUser.user.clientId}/elevate`,
        method: 'POST',
        data: {durationSeconds},
        headers: {
            Authorization: 'Basic ' + btoa(this.currentUser.user.name + ':' + password),
        },
    });
    await this.currentUser.tryAuthenticate();  // 刷新用户状态
};
```

**关键点**：
- 使用 Basic Auth 携带密码请求提升
- 成功后调用 `tryAuthenticate()` 刷新 `elevatedUntil`

#### 方式二：OIDC 认证

**流程** (`ui/src/ElevateStore.ts:47-88`)：

```
oidcElevate(durationSeconds)
    ↓
打开 popup 窗口 → /auth/oidc/elevate?id=clientId&durationSeconds=...
    ↓
服务端生成 state，存储到 pendingSessions（10 分钟有效期）
    ↓
重定向到 OIDC 提供商登录
    ↓
回调到 /auth/oidc/callback
    ↓
handleElevationCallback() → 验证后更新 ElevatedUntil
    ↓
前端轮询 popup 关闭，然后刷新用户状态
```

**服务端 OIDC 提升处理** (`api/oidc.go:235-266`)：

```go
func (a *OIDCAPI) handleElevationCallback(w http.ResponseWriter, elevate *pendingElevation, user *model.User) {
    client, _ := a.DB.GetClientByID(elevate.ClientID)
    // 验证 client.UserID == user.ID
    elevatedUntil := time.Now().Add(time.Duration(elevate.DurationSeconds) * time.Second)
    a.DB.UpdateClientElevatedUntil(client.ID, &elevatedUntil)
}
```

### 2.6 运行时权限注入

每次请求通过中间件时，权限检查是**实时**进行的：

1. **请求到达** → 中间件 `RequireElevatedClient` 执行
2. **提取令牌** → 从 Cookie/Header/Query 获取 token
3. **查询客户端** → `GetClientByToken(token)` 获取完整 Client 对象
4. **权限检查** → `checkClientElevated(client)` 比较 `ElevatedUntil` 与当前时间
5. **上下文注册** → `RegisterClient(ctx, client)` 将完整客户端信息存入请求上下文
6. **后续使用** → 业务处理通过 `auth.GetClient(ctx)` 获取客户端信息

**关键点**：
- 没有单独的"权限缓存"机制
- 每次请求都从数据库获取最新的 `ElevatedUntil`
- 因此提升权限后，后续请求立即生效

## 三、异常情况：权限回收与会话删除流程

### 3.1 权限自然过期

**机制**：`ElevatedUntil` 时间戳比较

**检查时机**：
- 每次请求进入 `RequireElevatedClient` 中间件时
- `checkClientElevated()` 函数实时比较

**过期表现**：
- 返回 403 Forbidden
- 错误信息：`"session not elevated, use basic auth or call /client:elevate"`

**代码** (`auth/authentication.go:259-260`)：
```go
if client.ElevatedUntil == nil || !timeNow().Before(*client.ElevatedUntil) {
    return authStateNotElevated, nil
}
```

**前端感知** (`ui/src/ElevateStore.ts:19-32`)：
```typescript
public refreshElevated = (): number => {
    const elevatedUntil = this.currentUser.user.elevatedUntil;
    if (!elevatedUntil) {
        this.elevated = false;
        return 0;
    }
    const ms = new Date(elevatedUntil).getTime() - 30_000 - Date.now();
    if (ms <= 0) {
        this.elevated = false;
        return 0;
    }
    this.elevated = true;
    return ms;  // 返回剩余毫秒数，可用于设置定时器
};
```

### 3.2 主动取消提升

**前端选项** (`ui/src/client/ElevateClientDialog.tsx:21-27`)：

```typescript
const durationOptions = [
    {label: 'Cancel elevation', seconds: -1},  // 取消提升
    {label: '1 hour', seconds: 60 * 60},
    // ...
];
```

**服务端处理**：
- `durationSeconds = -1` 时，`elevatedUntil = now + (-1)秒`
- 即设置为过去的时间，下次检查立即失效

### 3.3 用户登出（会话删除）

**API**：`POST /auth/logout` (`api/session.go:123-138`)

**处理流程**：

```
Logout(ctx)
    ↓
SetCookie(ctx.Writer, "", -1, a.SecureCookie)  // 清除 Cookie（MaxAge=-1）
    ↓
client := auth.GetClient(ctx)  // 获取当前客户端
    ↓
NotifyDeleted(client.UserID, client.Token)  // 通知流式连接断开
    ↓
DeleteClientByID(client.ID)  // 从数据库删除客户端记录
```

**关键代码** (`api/session.go:124-135`)：
```go
auth.SetCookie(ctx.Writer, "", -1, a.SecureCookie)  // 清除 Cookie
client := auth.GetClient(ctx)
a.NotifyDeleted(client.UserID, client.Token)  // 通知 stream handler
a.DB.DeleteClientByID(client.ID)
```

**数据库删除** (`database/client.go:51-54`)：
```go
func (d *GormDatabase) DeleteClientByID(id uint) error {
    return d.DB.Where("id = ?", id).Delete(&model.Client{}).Error
}
```

### 3.4 用户被删除时的级联处理

**API**：`DELETE /user/{id}` (`api/user.go:329-353`)

**处理流程**：

```
DeleteUserByID(ctx)
    ↓
检查是否是最后一个管理员（如果是 admin 用户）
    ↓
fireUserDeleted(id) → 触发所有删除回调
    ↓
DeleteUserByID(id) → 从数据库删除用户
```

**删除回调注册** (`router/router.go:103-105`)：

```go
userChangeNotifier.OnUserDeleted(streamHandler.NotifyDeletedUser)
userChangeNotifier.OnUserDeleted(pluginManager.RemoveUser)
```

**回调执行** (`api/user.go:42-48`)：
```go
func (c *UserChangeNotifier) fireUserDeleted(uid uint) error {
    for _, cb := range c.userDeletedCallbacks {
        if err := cb(uid); err != nil {
            return err
        }
    }
    return nil
}
```

**GORM 级联删除**：
- `model/user.go:12` - `Clients []Client` 关联
- 数据库迁移时创建外键关系
- 删除 User 时，关联的 Clients、Applications、PluginConf 自动删除

### 3.5 令牌主动失效

删除客户端记录即等同于令牌失效：

1. **数据库层面**：Client 记录被删除
2. **认证层面**：下次请求 `GetClientByToken(token)` 返回 nil
3. **结果**：中间件返回 `authStateSkip`，最终 401 Unauthorized

### 3.6 流式连接的断开通知

当客户端/用户被删除时，WebSocket 连接需要断开：

**通知机制** (`router/router.go:83, 89`)：
```go
clientHandler := api.ClientAPI{
    NotifyDeleted: streamHandler.NotifyDeletedClient,
}
sessionHandler := api.SessionAPI{
    NotifyDeleted: streamHandler.NotifyDeletedClient,
}
```

**Stream Handler** 维护活跃连接，收到删除通知后断开对应 token 的连接。

## 六、安全特性总结

### 6.1 令牌安全
- 22 字符随机令牌，约 2^132.5 的密钥空间
- 使用 `crypto/rand` 而非伪随机
- 数据库唯一索引防止重复

### 6.2 Cookie 安全
- `HttpOnly` - 防止 XSS 窃取
- `SameSite=Strict` - 防止 CSRF
- `Secure` - HTTPS 环境下只通过加密连接传输
- 7 天有效期，但会话可随时通过登出销毁

### 6.3 权限提升安全
- 需重新验证身份（密码或 OIDC）
- 提升有时间限制（默认可选 1 小时 ~ 1 年）
- 敏感操作要求提升状态，减少长期权限暴露

### 6.4 边界检查
- 只能提升自己的客户端（`client.UserID == auth.GetUserID(ctx)`）
- 管理员操作需要用户本身是 Admin
- 不能删除最后一个管理员
